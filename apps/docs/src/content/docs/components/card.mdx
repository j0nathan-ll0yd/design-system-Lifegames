The Card component is the primary container for widgets. It provides a glass-morphic background with optional accent color borders and hover effects.

## Usage

```astro
---
import { Card } from '@lifegames/web';
---

<Card accent="pink">
  <h3>Widget Title</h3>
  <p>Widget content</p>
</Card>
```

## Props

| Prop      | Type                                                                                            | Default | Description                              |
| --------- | ----------------------------------------------------------------------------------------------- | ------- | ---------------------------------------- |
| `accent`  | `'pink' \| 'green' \| 'blue' \| 'purple' \| 'amber' \| 'red' \| 'cyan' \| 'orange' \| 'indigo'` | --      | Accent color for the top border and glow |
| `loading` | `boolean`                                                                                       | `false` | Shows skeleton loading state             |
| `class`   | `string`                                                                                        | --      | Additional CSS classes                   |

## Accent Variants

Each accent color applies a colored top border and a subtle glow shadow that intensifies on hover.

## Loading State

When `loading` is true, the card applies the `is-loading` class which can be used to show skeleton placeholders and hide actual content.

## Accessibility

- The card uses `container-type: inline-size` for responsive container queries
- Hover effects are gated behind `@media (hover: hover)` to avoid sticky hover on touch devices
- Backdrop filter has a fallback for unsupported browsers
