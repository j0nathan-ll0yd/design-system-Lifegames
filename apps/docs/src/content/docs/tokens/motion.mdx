Motion tokens define consistent timing and easing across the system. All animations respect `prefers-reduced-motion`.

## Duration

| Token  | CSS Variable                  | Value |
| ------ | ----------------------------- | ----- |
| Fast   | `--lg-motion-duration-fast`   | 150ms |
| Normal | `--lg-motion-duration-normal` | 300ms |
| Slow   | `--lg-motion-duration-slow`   | 500ms |

## Easing

| Token      | CSS Variable                    | Value       |
| ---------- | ------------------------------- | ----------- |
| Standard   | `--lg-motion-easing-standard`   | ease-in-out |
| Decelerate | `--lg-motion-easing-decelerate` | ease-out    |
| Accelerate | `--lg-motion-easing-accelerate` | ease-in     |

## Keyframe Animations

Every shared keyframe has one definition, in `@j0nathan-ll0yd/tokens/motion`. The file also holds the `.skeleton-bar` and `.skeleton-circle` utilities, and it has no global rule. `@j0nathan-ll0yd/web/styles/components.css` and `primitives.css` import it, so a consumer of those stylesheets needs no second entrypoint. Import it directly for a surface outside the web package:

```css
@import '@j0nathan-ll0yd/tokens/motion';
```

`tokens/animations` and `tokens/effects` import the same file, so they provide every name too.

Curated animations: `glowPulse`, `dotPulse`, `statusPulse`, `shimmerSlide`, `fadeIn`, `fadeSlideRight`, `overlayFadeIn`, `modalScaleIn`, `ringPulse`, `avatarGlowPulse`.

## Reduced Motion

Every animation a web stylesheet names has its own `prefers-reduced-motion` gate. Most gates remove the animation under `reduce`. Two forms differ: view transitions keep a 0.001 s run so `animationend` still fires, and three `NotFound.css` pseudo-elements take `display: none`. `tokens/animations` and `tokens/effects` add a global rule that shortens every animation on the page. `tokens/motion` does not.

```swift
import LifegamesComponents

// iOS uses @Environment(\.accessibilityReduceMotion)
// MotionTokens provides duration constants
withAnimation(MotionTokens.standard()) {
    // animated change
}
```
