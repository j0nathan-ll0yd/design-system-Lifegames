The design system uses Space Grotesk as the primary typeface across all platforms.

## Font Family

- **Primary:** Space Grotesk
- **Fallback:** system sans-serif stack

## Type Scale

| Token | CSS Variable          | Web Size | iOS Text Style |
| ----- | --------------------- | -------- | -------------- |
| xs    | `--lg-font-size-xs`   | 0.7rem   | caption2       |
| sm    | `--lg-font-size-sm`   | 0.8rem   | caption        |
| base  | `--lg-font-size-base` | 0.9rem   | body           |
| md    | `--lg-font-size-md`   | 1rem     | callout        |
| lg    | `--lg-font-size-lg`   | 1.1rem   | title3         |
| xl    | `--lg-font-size-xl`   | 1.25rem  | title2         |
| 2xl   | `--lg-font-size-2xl`  | 1.5rem   | title          |
| hero  | `--lg-font-size-hero` | 2rem     | largeTitle     |

## iOS Font Registration

Consumers must register fonts at app launch:

```swift
import LifegamesTokens

LifegamesFonts.registerFonts()
```

Then use token factory functions:

```swift
Text("Title")
    .font(.Tokens.hero())
```
