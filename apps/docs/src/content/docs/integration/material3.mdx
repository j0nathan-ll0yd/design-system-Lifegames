title: Material 3 Integration
description: Using Lifegames Design System tokens with Material Web Components and Gemini-generated Material 3 Expressive UIs.
---

The `material3` Style Dictionary platform emits `--md-sys-color-*` CSS custom properties that match the Material 3 color role specification. Importing `m3.css` lets Gemini-generated Material Web Components (MWC) theme correctly off Lifegames tokens.

## Authority direction policy

**Lifegames semantic layer → M3 (unidirectional).** The mapping file `tokens/projections/material3/alias.json` is the authority. When M3 adds a new role:

1. Add the semantic primitive in `tokens/semantic/` first.
2. Then add the M3 alias entry in `alias.json`.
3. Never let M3 role additions dictate changes to the Lifegames semantic layer.

M3 deprecating a role is a no-op for us — we keep emitting until removal is safe.

## Building

```bash
pnpm build:m3
# Output: packages/tokens/dist/m3.css
```

Or as part of the full token build:

```bash
pnpm build:tokens
```

## Copy-paste import

```html
<!-- In your HTML or MWC host page -->
<link rel="stylesheet" href="path/to/@j0nathan-ll0yd/tokens/dist/m3.css" />
```

```css
/* Or via CSS @import */
@import '@j0nathan-ll0yd/tokens/dist/m3.css';
```

## Fixed-tone variants

Fixed-tone variants map primary and secondary roles to fixed values (not adaptive). Used in MWC components that need a stable tonal anchor.

| CSS custom property                         | Value     |
| ------------------------------------------- | --------- |
| `--md-sys-color-primary-fixed`              | `#818cf8` |
| `--md-sys-color-primary-fixed-dim`          | `#818cf8` |
| `--md-sys-color-on-primary-fixed`           | `#fafafa` |
| `--md-sys-color-on-primary-fixed-variant`   | `#9ca3af` |
