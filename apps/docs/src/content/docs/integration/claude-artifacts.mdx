# Claude Artifacts — shadcn/ui Integration

Claude Artifacts run on React 18 + Tailwind + shadcn/ui + Lucide + Recharts. Lifegames emits a
`shadcn.css` file with all 10 shadcn role vars (plus AI-surface extras) in OKLCH so any Artifact
rendered in Claude can pick up the brand with a single import.

## Quick start

```css
/* Paste this at the top of your Claude Artifact's global CSS */
@import url('https://cdn.jsdelivr.net/npm/@lifegames/tokens/dist/shadcn.css');
```

Or, if consuming from GitHub Packages after Phase 2 cutover:

```tsx
// In your Artifact's App.tsx or globals.css import
import '@lifegames/tokens/shadcn';
```

## Token mapping

All shadcn role vars map directly to Lifegames semantic tokens and are emitted in OKLCH
for wide-gamut display fidelity.

| shadcn var             | Lifegames semantic token | Resolved value (dark)            |
| ---------------------- | ------------------------ | -------------------------------- |
| `--background`         | `color.surface.base`     | `oklch(12.80% 0.0213 282.97)`    |
| `--foreground`         | `color.text.title`       | `oklch(98.51% 0.0000 0)`         |
| `--primary`            | `color.accent.indigo`    | `oklch(68.01% 0.1583 276.93)`    |

## AI-surface extras

The following vars are emitted as native `--lg-*` properties alongside the shadcn roles.
They have no shadcn equivalents but are essential for styling LLM-rendered surfaces:

| var                                 | Purpose                                      |
| ----------------------------------- | -------------------------------------------- |
| `--lg-color-surface-thinking`       | AI reasoning/thinking indicator background   |
| `--lg-color-surface-citation`       | Citation reference surface                   |
| `--lg-color-surface-tool-use`       | Tool-use disclosure background (indigo tint) |
| `--lg-color-surface-artifact-frame` | Artifact container frame                     |
| `--lg-color-surface-code-block`     | Code block background                        |

## Usage in a Claude Artifact

<Steps>

1. **Add the CSS import** at the top of your Artifact's style block:

   ```css
   @import url('https://cdn.jsdelivr.net/npm/@lifegames/tokens/dist/shadcn.css');
   ```

2. **Add `.dark` to your root element** (Lifegames is dark-first):

   ```tsx
   export default function App() {
     return (
       <div className="dark min-h-screen bg-background text-foreground">{/* your content */}</div>
     );
   }
   ```

3. **Use shadcn components normally** — they automatically pick up the OKLCH vars:

   ```tsx
   import { Button } from '@/components/ui/button';
   import { Card, CardContent } from '@/components/ui/card';
   import { Input } from '@/components/ui/input';

   export default function Demo() {
     return (
       <Card>
         <CardContent className="p-4 space-y-3">
           <Input placeholder="Type something…" />
           <Button variant="destructive">Delete</Button>
         </CardContent>
       </Card>
     );
   }
   ```

</Steps>

## Updating the mapping

The alias map lives at `tokens/projections/shadcn/alias.json`. It is a **mapping table**
(not a DTCG token file) and is excluded from DTCG validation.

**Authority rule:** Lifegames semantic layer is authoritative. shadcn role names are aliases
into our semantic layer — they never dictate changes to the semantic or primitive tiers.
