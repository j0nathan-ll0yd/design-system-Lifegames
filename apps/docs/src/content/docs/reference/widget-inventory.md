---
title: Widget Inventory
description: Canonical inventory of all widgets in the Lifegames Design System, including portfolio consumption status and Swift mirror coverage.
---

The canonical widget inventory is generated by `scripts/widget-inventory.mjs` and written to `docs/widget-inventory.json`. The README widget count is kept in sync automatically.

## Running the Inventory

```bash
# Generate docs/widget-inventory.json and update README count
pnpm widget:inventory

# CI drift-check mode — exits non-zero if README count diverges
pnpm widget:inventory --check
```

## Fields per Widget

| Field                 | Type    | Description                                                                                |
| --------------------- | ------- | ------------------------------------------------------------------------------------------ |
| `id`                  | string  | Widget name matching the `*.types.ts` filename stem                                        |
| `category`            | string  | Directory category (`github`, `health`, `identity`, `location`, `other`, `reading`)        |
| `hasStory`            | boolean | Whether a `*.stories.tsx` file exists alongside the types file                             |
| `hasSwiftMirror`      | boolean | Whether matching `*Props.swift` or `*View.swift` exists in `Sources/LifegamesWidgets`      |
| `schemaExempt`        | boolean | Whether the types file carries a `// schema-exempt:` comment (W16)                         |
| `consumedByPortfolio` | boolean | Whether the widget is imported from `@j0nathan-ll0yd/web/production` in the portfolio repo |

## `consumedByPortfolio` Algorithm

1. Script scans `~/Repositories/j0nathan-ll0yd.github.io/src/pages/*.astro` and `**/components/*.astro`.
2. Greps for `from '@j0nathan-ll0yd/web/production'` import blocks (multi-line regex).
3. Extracts named imports and marks matching widgets `true`.
4. If the portfolio repo is not present locally, falls back to reading `widget-consumers.json` at the repo root.
5. CI fails if the portfolio repo is unavailable **and** the fallback manifest is missing.

## CI Drift Detection

The `widget-inventory` job in `.github/workflows/ci.yml` runs `node scripts/widget-inventory.mjs --check` on every push and PR. The check fails if:

- The README widget count diverges from the script's actual count.
- `docs/widget-inventory.json` does not exist.
- The portfolio repo is unavailable and `widget-consumers.json` is missing.

## Inventory JSON Location

`docs/widget-inventory.json` — generated output, committed to the repo. Do not edit manually.

## Fallback Manifest

`widget-consumers.json` — root-level JSON listing portfolio-consumed widget IDs. Auto-written by `pnpm widget:inventory` and updated by `pnpm yalc:publish`. Used as CI fallback when the portfolio repo is not checked out.
