The Lifegames Design System provides a single source of truth for design tokens, reusable UI primitives, and page-specific widgets across web and iOS platforms.

## Features

- **DTCG Tokens** -- W3C Design Token Community Group format, emitted as CSS custom properties, Swift extensions, and JSON
- **Web Primitives** -- Card, Pill, Modal, PollStatus, Skeleton as Astro components
- **29 web + 30 Swift widgets** -- Full extraction of portfolio widgets with web + iOS parity
- **Accessibility** -- WCAG 2.2 AA contrast, skip-link, focus indicators, forced-colors support
- **Cross-platform** -- Shared fixture JSON validated against both TypeScript and Swift types

## Quick Start

### Web (npm)

```bash
pnpm add @j0nathan-ll0yd/tokens @j0nathan-ll0yd/web
```

```astro
---
import { Card, Pill } from '@j0nathan-ll0yd/web';
import '@j0nathan-ll0yd/tokens/css';
---

<Card accent="pink">
  <Pill href="/github" label="GitHub" />
</Card>
```

### iOS (Swift Package Manager)

Add the repository to your `Package.swift` dependencies:

```swift
.package(path: "../design-system-Lifegames")
```

```swift
import LifegamesTokens
import LifegamesComponents

struct MyView: View {
    var body: some View {
        MetricCardView(title: "Steps", value: "12,345")
            .neonCard(accent: .accentGreen)
    }
}
```
