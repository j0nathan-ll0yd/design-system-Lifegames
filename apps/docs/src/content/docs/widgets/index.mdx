The design system includes 56 page-specific widgets extracted from the Lifegames portfolio, each with full web (Astro) and iOS (SwiftUI) parity.

### Other (5 widgets)

## Data Contract

Every widget defines a TypeScript `Props` interface and a matching Swift `Props` struct. Both are validated against shared fixture JSON files in `Sources/LifegamesWidgets/Resources/widgets/`.

## Storybook

Each widget includes a Storybook CSF story for interactive development. Run `pnpm storybook` to browse all widgets.
