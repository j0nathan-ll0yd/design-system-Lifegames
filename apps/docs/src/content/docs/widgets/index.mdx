The design system includes 56 page-specific widgets extracted from the Lifegames portfolio, each with full web (Astro) and iOS (SwiftUI) parity. Detailed documentation for each widget lives at the per-widget pages linked from the sidebar, auto-generated from the manifest and fixture data.

Widget Storybook stories were removed in v0.1.1. Widget documentation lives at the per-widget pages linked from the sidebar (auto-generated from the manifest + fixture data).

## Categories

- [GitHub](/widgets/github/) — 29 widgets (ActivityFeed, ContributionCalendar, ProfileCard, etc.)
- [Location](/widgets/location/) — 10 widgets (CategoryTerrain, CityConstellation, WaffleGrid, etc.)
- [Health](/widgets/health/) — 5 widgets (DailyActivity, HeartRate, Hydration, etc.)
- [Reading](/widgets/reading/) — 4 widgets (Bookshelf, BookModal, ReadingFeed, TheatreReviews)
- [Identity](/widgets/identity/) — 3 widgets (BioTerminal, ComingSoon, IdentityCard)
- [Other](/widgets/other/) — 5 widgets (DndOverlay, FocusOverlay, GitHubHeatmap, OGImage, SystemStatus)

## Cross-Platform Parity

Every widget has a SwiftUI counterpart under `Sources/LifegamesWidgets/<Category>/`. Both platforms share fixture JSON files in `Sources/LifegamesWidgets/Resources/widgets/` and validate against the same data contract: a TypeScript `Props` interface on the web side and a matching Swift `Props` struct on iOS.
