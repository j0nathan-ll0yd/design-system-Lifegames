# Distribution Cutover: Complete

The cutover from local `yalc` links to a real npm registry is **complete (2026-08-01)**.
Consumers resolve `@j0nathan-ll0yd/{copy,tokens,schemas,web,fixtures}` (and
`@j0nathan-ll0yd/portal-contract`, published from `mantle-LifegamesPortal`) from
**GitHub Packages** at `^1.0.0`.

It shipped by a **different route than this page originally predicted**: there was no
`vars.REMOTE_ENABLED` flip and no `publish.yml`. Publishing runs from
`.github/workflows/publish-ds-packages.yml` (Changesets — triggered by a `ds-v*` tag or
manual dispatch); `@j0nathan-ll0yd/config` ships from its own `publish-config.yml`.

**No PAT is required** — all packages are **public**, so CI installs with the built-in
`GITHUB_TOKEN` and `permissions: packages: read`. One non-obvious wrinkle (it cost a failed
publish): the two toolchains authenticate separately — **pnpm** needs
`pnpm config set '//npm.pkg.github.com/:_authToken' "$TOKEN"` for installs, and **npm** needs
its own `npm config set` for `changeset publish`.

`yalc` is **fully retired** — no `file:.yalc/*` dependency remains anywhere in the estate.

Full record: atlas decision `0015-yalc-retirement-registry-migration`.
