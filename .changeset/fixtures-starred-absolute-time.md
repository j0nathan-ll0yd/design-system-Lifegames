The StarredRepoList post-adapter fixtures (`src/post-adapter/starredRepos.*.json`) carry `starredAt` as absolute UTC text (`2026-03-16 12:00 UTC`) in place of a relative label (`2 days ago`). They are generated by the real `adaptStarredRepos`, which now writes that form (atlas decision 0164 D5). The shape is unchanged; the displayed values change, so this is minor.

Consumer note: a test that treats every post-adapter baseline string of 12 or more characters as a leaked legacy value now sees these instants. `2026-03-09 12:00 UTC` is also the text the known-answer StarredRepoList renders without JavaScript. Exclude absolute instants from such a marker set, as ISO timestamps are.
